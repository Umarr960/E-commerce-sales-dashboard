# 🛒 E-Commerce Sales Dashboard \| Power BI

An interactive **E-Commerce Sales Dashboard** created using **Microsoft
Power BI** to analyze sales performance, quantity, profit, customers,
products, states, categories, and payment methods.

## 📊 Dashboard Preview

![E-Commerce Sales Dashboard](dashboard.png)

## 🎯 Project Objective

The main objective of this project is to transform e-commerce sales data
into an interactive dashboard that helps users quickly understand
business performance and identify important sales trends.

## 📈 Dashboard Features

### 1. Sales by State

A horizontal bar chart shows the **Sum of Amount by State**, helping
compare sales performance across different states.

### 2. Quantity by Category

A donut chart displays the contribution of different product categories:

-   Clothing
-   Electronics
-   Furniture

### 3. Monthly Profit Analysis

A monthly chart shows **profit trends throughout the year**, making it
easier to identify high- and low-performing months.

### 4. Sales by Customer

A bar chart compares the **Sum of Amount by Customer Name** to identify
customers contributing significant sales.

### 5. Quantity by Payment Mode

A donut chart analyzes the quantity of orders by payment method,
including:

-   COD
-   UPI
-   Debit Card
-   Credit Card
-   EMI

### 6. Profit by Sub-Category

A horizontal bar chart compares profit across product sub-categories
such as:

-   Printers
-   Bookcases
-   Saree
-   Accessories
-   Tables

### 7. Interactive Filters

The dashboard includes interactive filters for:

-   **Quarter:** Qtr 1, Qtr 2, Qtr 3, Qtr 4
-   **State:** Select a specific state or view all states

These filters allow users to explore the data dynamically.

## 🚀 How to Use

1.  Download or clone this repository.
2.  Open the `.pbix` file using **Microsoft Power BI Desktop**.
3.  Refresh the data if the original dataset is available.
4.  Use the quarter and state filters to interact with the dashboard.
5.  Explore sales, quantity, profit, customers, categories, and payment
    methods.
